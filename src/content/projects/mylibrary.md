MyLibrary is a library management application built with Laravel. It brings the core tasks of running a library together in one place, from maintaining the catalogue to managing borrowing activity.

## What it supports

- **Book inventories:** keep track of the library's book collection.
- **Borrowing activities:** organize and manage book loans.
- **Role-based accounts:** support administrator and borrower experiences.

The project is designed to simplify day-to-day library management while keeping access organized around each user's role.
